# ALBIS 0.9.15: The App Finally Talks Back

This is the polish release. For a few versions ALBIS quietly swallowed its feelings — failed loads, broken exports, and dropped streams all disappeared into the void with nothing but a faint footer note you probably missed. Not anymore.

## Highlights

- **Notifications that actually notify.** Errors, warnings, and "done!" confirmations now pop up as toasts instead of whispering into the status bar.
- **Save As that can actually choose a folder.** The old dialog let you type a path and then quietly ignored it (browsers always dump downloads in one place). Save As now opens your real OS save panel — navigate, name, confirm, done. Browsers without it fall back gracefully.
- **No more 1990s browser dialogs.** The native `prompt()` / `confirm()` boxes are gone, replaced by proper in-app modals that match the rest of the UI and speak your language.
- **A tidier File menu.** Export and Save As were doing the same job twice; now there is one Save As menu. Convert Dataset stays right where it is.
- **More polish.** Localized the About dialog, swept up stray English placeholders, explained greyed-out controls, and tidied a few titles.

## Why This Matters

A viewer you trust is one that tells you what happened. If a frame fails to load or an export goes sideways, you should know right away — not find out later when the image never showed up.

## For Contributors

The Developer Guide now has a real frontend architecture map: how state, controllers, bindings, and the composition root fit together, the two wiring patterns, and a worked example. New here? Start there.
