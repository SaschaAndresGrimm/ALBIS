Fixes from the first days with the beta Detector tab on a real detector, and a tidier Detector tab.

### Fixed

- **Long panel sections are no longer cut off.** An open section stopped at a
  fixed height, so on a real detector the end of Advanced could not be reached.
  This affected every tab with a long section.
- **The tab bar no longer lets scrolled content show through.**
- **The backend log no longer wobbles while following.** Help → View Backend
  Log reloads quietly every few seconds, instead of pushing the log down and
  back each time.
- **On Windows, Show in folder brings Explorer to the front** after downloading
  an update, with the installer selected. Help → Open log comes to the front
  too.

### Changed

- **The Detector tab takes less than half the room.** Every setting is one
  line; series, timing and energy sit side by side on a wide panel; the
  Acquisition header sums up the next series ("100 images · 10 s").
- **Thresholds, one to four.** Each threshold is one row with its energy, and an
  **Images** row says which images the detector delivers (each threshold's, the
  difference image), with a warning when none is selected.
- **Shorter cards.** Once connected, the address shrinks to a line under the
  detector's name. The file writer's next file, free storage and data page sit
  on one line, and explanations moved into the **?** beside each item.
- **Every on/off setting is a switch,** and Advanced shows detector information
  as a compact table.

### Security

- **The Detector tab's data-page link is only made from an http(s) address.**
- **The SIMPLON API version check can no longer be slowed down** by a long input.

---

Update if you use the beta Detector tab, or if a long panel section was cut off
for you. The Detector tab stays hidden until you switch it on under Settings →
Viewer.
