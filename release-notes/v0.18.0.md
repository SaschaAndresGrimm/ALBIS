Double-click an `.h5` and it opens. Headers that survive an export. And one
5,000,000-link master file that used to take the whole viewer down with it.

### Added

- **Double-click to open.** `.h5`, `.hdf5`, `.cbf`, `.edf`, `.tif` and `.tiff`
  now open in ALBIS from the file manager, on Windows, macOS and Linux. If
  ALBIS is already running, the file lands in the copy that is running. On
  Windows it joins the *Open with* list rather than stealing the extension —
  HDFView keeps working, and you pick ALBIS once to make it the default.
  `.cfg` and `.cbf.gz` are left alone on purpose: one belongs to every other
  program's config, and the other is really just `.gz`.
- **File → Duplicate Window** (`⇧⌘N`) opens the current image again with
  everything set the way you have it — frame, colour map, contrast, zoom, mask,
  rings, ROI. Independent, not linked; the toolbar still joins them if you want.
- **Browse buttons** for the log and data folders in Settings. Typing a path
  and finding out at the next restart was not a great deal.

### Fixed

- **The master file that ate the viewer.** An ARINA burn-in master written one
  file per frame — 5,000,000 external links, none of the data files downloaded
  — hung ALBIS for six minutes, then needed 7.2 GiB to draw a file tree.
  HDFView died on it too, which is why it looked corrupt. It was not: it was
  half a download. It now answers in about two seconds and tells you which data
  files are missing, by name, in your language. Group listings stop at 10,000
  children and say so. And a partly-downloaded series still opens and still
  shows the frames that did arrive.
- **Exported headers stop forgetting things.** A converted CBF restated six of
  its source's twenty header lines; now it manages sixteen — detector model,
  serial, timestamp, sensor thickness, tau, threshold, gain, rotation angles.
  Exported TIFFs carry the same text instead of three lines of provenance, and
  a summed HDF5 keeps the detector and beam metadata a NeXus writer states as
  datasets. A TIFF from **Series Operations** had no header at all. It does now.
- **Pixel value labels stay inside their pixel.** At a 50× zoom on a detector
  counting into the millions they ran straight over the cell borders, and the
  abbreviation that should have kicked in was never reached.
