# ALBIS 0.10.7: Older, Wiser, Still Runs

A small maintenance release. The headline: the Linux AppImage runs on older distributions again — it was accidentally built to require a newer glibc than many machines have. Plus two quality-of-life fixes for the cursor and log output.

## Highlights

- **Linux AppImage runs on Ubuntu 22.04 (and other glibc 2.35 systems) again.** Recent builds required `GLIBC_2.38` and crashed on startup with `version 'GLIBC_2.38' not found`; a follow-on packaging issue then broke `import numpy`. Both are fixed, and a CI guard now fails the build if a future artifact would require a newer glibc than the oldest supported target.
- **Normal arrow cursor over the image.** Hovering a pannable (zoomed) image now shows the standard arrow instead of an open-hand "grab" cursor that rendered as a distracting glove on some Linux themes. The closed-hand still appears only while actively dragging.
- **The configured log level is finally respected.** Setting `logging.level` to `CRITICAL` now also silences uvicorn's access log (`INFO: ... "GET /api/health" 200 OK`), which previously kept printing regardless.
