# ALBIS 0.10.1: Mind Your Manners (And Your Keyboard)

0.10.0 handed you the mouse and let you drag the rings around. 0.10.1 is the release that learned some manners: the whole menu system now works without a mouse, screen readers finally know what everything is called, error messages speak human in 13 languages, and slow requests stop hanging the spinner forever. A patch bump made entirely of "wait, that should've always worked like this."

## Highlights

- **Drive the menus from the keyboard.** Arrow keys now walk the menu bar and dropdowns — Up/Down between items, Left/Right between menus, Home/End to the ends, ArrowDown to open. Escape closes and hands focus back where it belongs. The "Save As…" submenu opens with Right/Enter/Space. Arrow keys only get claimed while a menu is open, so frame stepping still works the rest of the time.
- **Screen readers get the whole story.** A full ARIA pass: the menu bar is a proper menubar/menu/menuitem tree, the command palette is a real combobox+listbox with active-option tracking, peak-finder rows announce their #/X/Y/intensity and selection state, and inspector group toggles report expanded/collapsed. Focus is now *visible* everywhere too — 15 controls gained `:focus-visible` rings so you can always see where you are.
- **Errors that talk like a person.** Network and HTTP failures used to surface as raw `Request failed: 500` strings. They're now friendly, localized messages (13 locales) that carry status and detail under the hood — including a proper "couldn't reach the server" message instead of a cryptic stack.
- **No more eternal spinner.** Image, series, and dataset requests gained timeouts (30s headers, 60s scans, 120s frame loads). This also squashes a latent bug where a timed-out frame load got silently swallowed and left the loading spinner up forever.

## Also Fixed

- **Ring labels stay attached to their rings.** The new label collision-avoidance was nudging crowded labels *outward along the radius*, which could fling a middle ring's label clear past the outer ring. Labels now slide along the ring tangent instead, staying glued to the ring they describe (and biased upward, away from the beamstop).
- **A less cluttered ROI panel.** Killed the duplicated "Box ROI active" status line when a region is live (the badge and stats already say so), gave the stats grid real label/value hierarchy and a column divider, and stopped resolution-ring labels from piling up on the same ray.

## Under The Hood

- **Ready to be open source.** Added `THIRD_PARTY_LICENSES.md` plus verbatim Apache-2.0 and MPL-2.0 texts, bundled into the packaged app, so every shipped dependency is properly attributed ahead of the MIT release.
- New test suites lock the contracts down: menu keyboard navigation, menu ARIA, command-palette ARIA, and the HTTP error/timeout layer.
- Contrast was audited against WCAG AA across every text/accent token — all real text passes, so no colors needed changing.
