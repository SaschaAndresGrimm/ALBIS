**I Can See Clearly Now:** a magnifier, Tilman's idea, for everyone who needs a closer look (Tilman included: he needs glasses too).

### Added

- **A magnifier.** Hold **Z** and a round lens at the mouse shows the pixels
  under it enlarged. It is drawn from the data, not from the screen, so each
  pixel is a crisp square even with the whole detector on screen.
  - The mouse wheel changes its magnification (2× to 32×), **Shift + wheel** its
    size; both are remembered.
  - The **🔍** button in the toolbar, or **View: Magnifier On/Off** in the command
    palette, keeps it on.
  - It uses the image's colour map, contrast and mask colours, and follows
    flatfield correction and inpainting.
  - Once pixels are large enough, it prints their values, sized to fit each
    pixel, and outlines the pixel under the mouse.
  - It never appears in exports.

### Fixed

- **The file list can no longer hang.** Opening a file could leave the Data
  source section on "Loading file list…" for good when a browser extension held
  up the response. It now gives up after 20 seconds, says so, and the file
  still opens.
