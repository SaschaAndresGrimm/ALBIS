A fix for the Linux build: ALBIS opens your browser again.

### Fixed

- **Linux: the browser opens again.** On Rocky Linux 9, and probably other
  current distributions, 0.21.0 printed "opening browser" and nothing
  happened. The browser ALBIS started loaded one of ALBIS's own bundled
  libraries in place of the system's and crashed. Programs ALBIS starts now
  get the system's libraries, and the bundle no longer carries that library at
  all. The same fix covers **Show in Folder** and the file pickers.
- **Linux: no more silent "opening browser".** When there is no browser to
  start, for example over SSH, ALBIS now says so and prints the address to
  open.
- Every release is now also tested on Rocky Linux 9, including a check that
  the browser ALBIS starts gets the system's libraries.

---

Only the packaged Linux build changes. On Linux, update from 0.21.0; on macOS
and Windows there is no need to.
