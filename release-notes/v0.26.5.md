**Smooth Operator:** ROIs that stay out of the way and keep up with the pointer, Convert Dataset for live images, and exports that read back as a series. 0.26.2, 0.26.3 and 0.26.4 were tagged but never published; this release carries their changes too.

### Added

- **Convert Dataset works for live sources.** With the SIMPLON monitor, a
  JUNGFRAUJOCH preview or the Remote Stream as the source, File → Convert
  Dataset saves the current image or every image in the live history as TIFF or
  CBF, with the energy, distance and beam centre the source reported. Before, it
  failed with "File not found".

### Changed

- **An ROI no longer gets in the way.** Inside an ROI a drag now pans the image
  like anywhere else; the ROI moves by its centre handle, which a box now has
  too. The centre is a crosshair with a dark outline, easy to see on a bright
  image, and the cursor shows what a drag will do.
- **The detector's data page sits with the files** in the beta Detector tab:
  a small ↗ beside "Files on the detector".
- **Wording for any lab or facility.** The Detector tab and the documentation
  no longer assume a beamline.

### Fixed

- **Large ROIs move and resize smoothly.** The statistics no longer hold up
  the outline while you drag, and they are about 3.5 times faster on large
  regions, with the same results.
- **Converted images read back as a series.** Files are named like a detector's
  own images, the number last: `series_190_00007.cbf`, or
  `series_190_thr2_00007.cbf` with several thresholds. ALBIS, XDS, DIALS and
  ALBULA now read an export as a series of frames.
- **A detector address that does not answer no longer half-switches the
  Detector tab.** The detector already connected stays connected until the new
  one answers; Cancel goes back to it.
- **The Intel Mac build is back.** GitHub's Intel macOS runners could no
  longer fetch Apple's notarization tickets, which kept 0.26.2 to 0.26.4 from
  being published. The Intel app is now notarized there and finished on an
  Apple-silicon runner: still signed, notarized and stapled, still checked.

---

Update if you work with ROIs on large images, convert datasets, or use the beta
Detector tab. Files converted with an earlier version keep their names; convert
again to get the new ones.
