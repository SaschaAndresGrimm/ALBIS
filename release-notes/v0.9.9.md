# ALBIS 0.9.9

ALBIS `0.9.9` is a focused bug-fix release for one of the most annoying possible viewer behaviors: zooming into the interesting part of the detector and then getting told, politely but firmly, that the edge is not allowed to live there.

## Highlights

- Fixed the viewport pan clamp so zoomed images no longer snap back toward an edge when you try to center the top or side rows.
- Fixed the high-zoom visibility guard so it keeps just a small reachable sliver on screen instead of demanding that a large chunk of the image remain visible.
- Added regression coverage for the zoom-threshold and edge-pan cases so this behavior is less likely to sneak back in later.

## Why this release exists

Because a diffraction viewer should help you inspect detector edges, not develop emotional attachments to them.

## Release nicknames

- No More Top-Edge Tantrums
- Zoom In, Stay There
