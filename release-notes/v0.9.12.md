# ALBIS 0.9.12: Mind the Gaps, Export the Frames

This is the data-export release.

ALBIS can now take detector datasets and image series out of the viewer and into the wider crystallography world as TIFF or CBF, with the important detector breadcrumbs still attached.

## Highlights

- New **File -> Convert Dataset...** workflow for batch conversion to TIFF or CBF.
- New shortcut: `Cmd+Shift+X` on macOS, `Ctrl+Shift+X` elsewhere.
- HDF5 datasets can be exported as all frames, the current frame, or a frame range.
- Multi-threshold datasets can export the current threshold or all thresholds.
- TIFF exports carry Dectris-style header metadata in private tag `0xC7F8`.
- CBF exports carry miniCBF-style `_array_data.header_contents`.
- Gap pixels export as `-1`; bad and saturated pixels export as `-2`.
- Completed conversions can jump straight back into ALBIS with **Open Image**.

## Detector Metadata

When the source provides it, ALBIS now carries over detector identity, pixel size, exposure, wavelength/energy, detector distance, beam center, threshold energy, and rotation information.

The exporter has also learned a real-world Dectris/Jungfrau quirk: saturated `uint32` sentinel pixels stay compact and meaningful as `-2` instead of turning the output into oversized 64-bit images.

## Tested On Real Data

The new path was smoke-tested with `test_560_master.h5`, a 10-frame `2170 x 2070` Jungfrau-style stack:

- TIFF: 10 files in about 0.9 seconds
- CBF: 10 files in about 0.9 seconds
- Output dtype: signed `int32`
- Gap pixels: `-1`
- Saturated pixels: `-2`
