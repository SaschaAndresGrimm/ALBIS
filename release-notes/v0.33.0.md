**The Fellowship of the Tab:** the Analysis tab gathers its tools, lets each user keep only the ones they need, and gets more than three rings to rule them all.

### Added

- **Show only the tools you use.** **Settings → Tools** chooses which tools the
  Analysis tab shows: Resolution Rings and Peak Finder for diffraction,
  Flatfield and Inpainting for imaging, Combine Frames for processing.
  **Diffraction**, **Imaging** and **Everything** set them in one click.
  - A hidden tool is switched off, so nothing acts on the image out of sight.
  - While a tool is hidden, the bottom of the Analysis tab says so, with
    **Customise…** to bring it back.
  - Facilities can preset it in the config file (`ui.hidden_tools`).
- **As many resolution rings as you need.** Add and remove rings freely, up to
  16. **Ice rings** adds the ten rings of hexagonal ice in one click. Your rings
  are remembered for the next session.

### Changed

- **Series Operations is now Combine Frames, in the Analysis tab.** It asks two
  separate questions: which frames (all or a range, and every Nth) and how many
  images (one, or one per N frames).
- **Normalisation is gone from Combine Frames.** It did what the Flatfield
  section does better, for any image. A sum of whole counts is written as
  whole counts again.
- **A flat from many frames in two clicks.** **Make one from frames…** in
  Flatfield sets up Combine Frames to average a run into one TIFF, and **Use as
  flat** takes the result.
- **The Detector tab's switch moved to Settings → Tools.**

### Fixed

- **Combining 16- or 32-bit TIFF or CBF frames keeps their gaps as gaps.** A
  gap's value was combined as a count. The result showed a bright pixel instead
  of a gap, so Inpainting had nothing to fill.
- **The ALBIS wordmark no longer flickers** in a fallback font on start.

---

Update if you combine frames, make flats, or use resolution rings. Series
Operations now lives in the **Analysis** tab as **Combine Frames**, and the
Detector tab's switch is under **Settings → Tools**.
