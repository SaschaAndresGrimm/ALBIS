# ALBIS 0.10.6: Browse Like You Mean It

The file browser got a full glow-up this release. It opens bigger, defaults to the view you actually want, sorts by clicking a column like every other file manager on earth, remembers where you were, lets you type a path, and stopped doing the little annoying things it used to do. Same dialog, a lot less friction.

## Highlights

- **A bigger window that actually fills the screen.** The picker was capped at a small fixed height with a stubby scrollbar while half your monitor sat empty. It now scales to a large, responsive size and the file list expands all the way to the bottom — far more files at a glance before you ever scroll.
- **Sort by clicking the column header.** In Details view, click **Name / Type / Modified / Size** to sort; click again to flip the direction, with a caret showing which way. Size and reverse-Type sorting are new, and the header and the Sort dropdown stay perfectly in sync.
- **Opens the way you work.** Details view and **First image only** are now the defaults — you land on a tidy, columned list with each acquisition collapsed to its master/first image, instead of a flat wall of `_data_00000N` files.
- **Type or paste a path.** The Path field is editable now: type a directory and hit Enter to jump straight there (a file path drops you in its folder). Type something that doesn't exist and you get a clear *"Path not found"* instead of being silently teleported to Root.
- **Search that finishes the job.** Hit **Enter** in the search box to jump to the first match — and if it's the only match, it opens. Folder/file counts now show right in the section headers (`Image Files (241)`), and a failed load offers a one-click **Retry**.

## Under The Hood

- Your selection now survives a re-sort: reloading the same directory restores the highlighted file by path, so the Select button doesn't blink off when you reorder.
- The series and sort choices are no longer clobbered when you pass through a folder that can't use them — the control just disables and your choice returns on the next compatible folder.
- Folder-select mode is a true folder picker: the file list and file-only filters step aside so you can't accidentally pick a file when a folder is required.
- Last-visited directory is remembered across sessions (with a safe fall-back to Root if it's since vanished), and the browser focuses the first entry on open for immediate keyboard navigation.
- New backend `requestedPathMissing` flag on `/api/browse`, plus `type_desc` / `size_asc` / `size_desc` sort modes. New i18n strings localized across all 13 locales.
