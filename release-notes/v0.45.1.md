**These Aren't the Bugs You're Looking For**: a patch release that fixes noise and TIFF export on floating-point images, and replaces the tool hints with tooltips that are always on.

### Changed

- **Tooltips are always on.** Icon-only buttons show their name and keyboard
  shortcut, and a greyed-out control says why. The "Enable tool hints" setting
  is gone; a config file that still sets it keeps loading.
- **Convert Dataset is grouped** into what to write, Corrections and Output.
  The file names are previewed, and long names show their end.
- **The Data Source tag** shows the mode ("File") without the file name.

### Fixed

- **TIFF export keeps floating-point values.** Float images were rounded to
  whole numbers; with Data type on Automatic they are now written as 32-bit
  floats.
- **Add Poisson noise suits images of fractions.** Filled gaps no longer show
  as a pattern of whole numbers.
- **The start screen no longer crops the DECTRIS wordmark** in a tall or
  zoomed-out window.
- **The Data Source status** no longer falls back to "Choose an image source to
  begin." after a language switch.

---

Everyone can update, in particular anyone exporting floating-point data to
TIFF or filling gaps in normalised images. The full list is in the
[changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
