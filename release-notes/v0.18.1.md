macOS only. If you are on Windows or Linux, 0.18.0 is fine — nothing here
touches you.

0.18.0 taught ALBIS to open files you double-click. On macOS it managed that
twice as badly as it sounds, and a tester found both halves within minutes.

### Fixed

- **Nothing running → an empty window, no file.** macOS does not pass a
  document's path on the command line. It sends an Apple Event, and on a cold
  start that lands while ALBIS is still booting its server — before anything
  exists to catch it. It is caught before Python even starts now.
- **Already running → the image, *plus* an empty window.** Opening a file on a
  running app delivers two things, the activation and the document, in
  whichever order it feels like. The activation kept winning and opening a
  blank viewer next to the real one. It waits a beat now, and the file cancels
  it. A plain Dock click is unaffected — the beat is 0.45 s and you will not
  notice it.

Both fixes live in the packaged app, so this needs the `.dmg`, not a
`git pull`.
