A way to stop ALBIS, thanks to Benj for asking for it, and uploads that no longer
get stuck on a half-copied file, thanks to Filippo for reporting it.

### Added

- **File → Quit ALBIS.** ALBIS runs as a small server behind its browser tab,
  and on Windows and Linux closing the tab left it running, holding memory and,
  on Windows, keeping its open HDF5 files locked. **File → Quit ALBIS** (or
  **ALBIS: Quit** in the command palette) now stops it. It asks first only while
  a conversion, an export, a series sum or a live watch is still running.
- **ALBIS stops by itself 15 minutes after its last tab closes**, unless a
  conversion or series sum is still writing. Set `launcher.idle_shutdown_min` to
  change the delay, or to `0` to keep it running.
  - Both apply only to ALBIS started on your own computer, not to a server
    shared on the network or the Docker image.

### Fixed

- **An upload that stops short is refused instead of kept.** A detector file
  picked while it was still being written or copied arrived cut off, was saved
  as if complete, and could not be opened. Worse, every retry reopened that
  broken copy instead of uploading again. ALBIS now refuses an incomplete upload
  and says so: wait until the file is finished, then upload it again. A file
  already on the server is reused only when it is complete and the same size.
- **A refused upload says why** in the status bar, instead of only "Failed to
  upload selected files".

---

Update if you run ALBIS on Windows or Linux and want a clean way to stop it, or
if you upload files to a remote ALBIS. Quit is in the **File** menu.
