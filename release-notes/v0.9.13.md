# ALBIS 0.9.13: Cogs, Logs, and Zero Floors

This is the ROI statistics plot tune-up release.

The statistics panel got more deliberate: each plot now owns its own settings, histograms stopped pretending negative counts are a thing, and manual axis limits are close enough to adjust without redecorating the whole interface.

## Highlights

- ROI histogram y-axes now stay at or above zero.
- Histograms can use Auto bins or a fixed bin count selected from the plot's settings menu.
- X profile, Y profile, and histogram plots each have their own cog menu.
- Log scale moved into the individual plot menus so each plot can choose its own math mood.
- Manual X/Y axis min/max controls are available per plot.
- Axis spinner changes redraw plots continuously while you hold the arrows.
- Plot settings menus now float outside the chart frame, so tall menus remain usable instead of getting clipped.
- The old global ROI plot Log plot and Autoscale checkboxes have been retired.

## Also Included

- Azure Artifact Signing support for Windows release signing workflows.
- Release input verification now keeps optional Windows/macOS signing optional unless a signing setup is only partially configured.
- Refreshed GitHub Actions, Python, and npm dependency pins.
- Dev npm audit cleanup.
