A cosmetic release: the installers now look like ALBIS.

### Added

- **macOS: the DMG opens to a designed window.** Earlier releases opened as a
  bare Finder window. It now has a light background with the ALBIS ridge, and a
  big arrow from `ALBIS.app` to `Applications`, so installing is one drag.
- **Windows: the installer wears ALBIS artwork.** Inno Setup's stock blue
  banner is gone. Every page now carries the same light gradient and ridge as
  the DMG, with the ALBIS icon on it, and the images ship at every DPI step so
  they stay sharp on high-DPI screens. That includes the small progress window
  that **Install Update** shows.
- The Windows installer is now built with a pinned Inno Setup (6.7.1), so
  building the same release twice gives the same installer.

### Fixed

- A live-acquisition test that failed now and then on Windows CI. It exposed a
  real Windows quirk: HDF5 file locks there are mandatory, so a writer on
  Windows (or writing to an SMB share) can have its final close refused while
  ALBIS is reading the file. Linux and macOS are unaffected.

---

No change to how ALBIS opens, reads or displays your data. If 0.20.1 is
running fine, **Help → Check for Updates** will offer this whenever it suits
you.
