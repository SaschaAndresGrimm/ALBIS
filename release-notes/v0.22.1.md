Two fixes from user feedback, and explanations where the options needed them.

### Fixed

- **Auto contrast works on cosmics and other nearly empty frames.** On a frame
  that is almost all background with a few hits, auto contrast set the
  foreground to 0, the same as the background, and drew every hit saturated.
  It now takes the foreground from the hits themselves, so they show with their
  real differences. Frames with more signal look exactly as before.
- **A DIALS geometry file now gives the right rings for any detector.** A
  `dials.import` file for an ordinary flat detector put the detector behind the
  sample, so the rings and resolution values were wrong; only the I23
  detector's file happened to work. ALBIS now reads these files the way DIALS
  does, and agrees with DIALS's own resolution values.

### Added

- **A "?" next to options that need more than a label**: Series Operations'
  Mode, Operation and Normalization, the mask options, and the geometry file.
  Hover over it, or click or tap it to keep the explanation open.
- **What a geometry file must contain** is now documented in the Power User
  Guide, with how to make one and a minimal example.

---

Nothing changes for data that already displayed well. Update if you look at
sparse frames such as cosmics, or use a geometry file for a detector other than
I23's.
