**Honey, I Shrunk the app.js**: a release you will mostly not see. Behind the scenes, ALBIS was reorganised for the people (and the AI assistants) who work on it: its biggest files shrank, every request to the server now reports failures the same way, and a new automated check drives ALBIS through every live source before a change can land. The one thing you will notice: when a save fails, ALBIS now tells you why.

### Changed

- **When saving the known detectors, Settings or a pixel mask fails, ALBIS
  says why, in your language.** Where it used to show only `HTTP 500` or
  `Save failed (500)`, it now shows the server's own reason when there is one
  (a full disk, a value out of range), or a translated message saying whether
  the server, the network or the request failed.
- **Under the hood: tidied for the people and AI assistants who maintain
  ALBIS.** Nothing is meant to look or work differently. The main script
  shrank by more than a third, the stylesheet went from one 9,000-line file
  to seventeen named by what they style, and every live source (SIMPLON,
  JUNGFRAUJOCH, the Remote Stream API, folder watch) is now exercised by an
  automated check on every change.

---

**A word of caution.** We moved a lot of furniture, a few thousand lines of it,
and checked every room twice: against simulated detectors, a simulated
JUNGFRAUJOCH stream and a real PILATUS4. Still, when a shrink ray is involved,
something small can end up under the sofa. If anything behaves differently
from 0.38.1, that is a bug: please report it, with Help → View Log if you can.

Everyone can update; nothing moved for users. Contributors will find the new
live check in `docs/LIVE_TEST_PLAN.md`, and in decisions 0005 and 0006 how the
frontend's parts find each other.
