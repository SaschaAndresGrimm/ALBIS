A hardening release ahead of 1.0, from a full review of the repository against
what an open-source launch has to stand up to. Nothing here changes how ALBIS
is used; most of it is about numbers being right, keyboards working, and the
release itself being verifiable.

## Fixed numbers

Three paths could report a plausible value that was wrong — the worst failure
mode a scientific viewer has:

- **Resolution from a guessed beam centre.** When a file carried no beam centre
  and none had been typed, the image midpoint was substituted and Ångström
  d-spacings were reported and exported to CSV as if calibrated. A real beam
  centre sits tens to hundreds of pixels away. The numbers now wait until the
  centre is known; the rings still draw so you can drag it into place.
- **A detector distance read 1000× short.** An undeclared distance between 0.5
  and 10 was taken as millimetres, so 0.8 m became 0.8 mm and every d-spacing
  derived from it was rescaled.
- **MYTHEN frames losing half their channels.** A counts-only frame was always
  parsed as `<channel> <count>` pairs, dropping every other channel and shifting
  the rest, then zero-padding back to full width so the shape still looked right.

The Bragg implementation was always correct. `hc` and the conversion now live in
one place per language instead of nine, so the rings and the peak table cannot
drift apart, and the planar path has numerical tests with values computed
offline rather than round-tripped through its own formula.

## Security

- A crafted HDF5 file could read any file the server could open, through virtual
  dataset sources and external raw-data storage — mechanisms libhdf5 resolves
  below h5py, so the existing confinement never saw them. Both are now confined
  the same way external links are. Ordinary multi-file detector output still
  opens.
- `GET /api/simplon/monitor` sent a state-changing `PUT` to the detector and was
  not guarded against cross-site requests, so a page you visited could reach
  your detector. Four stream routes are now guarded, and neither the address nor
  the API version can steer the request off the SIMPLON API any more.

## Accessibility

`Tab` was bound to play/pause with an unconditional `preventDefault()`, so
keyboard focus could not move through any of the window's controls. It now
yields to focus traversal and still works as a shortcut from the image. The
focus indicator was below the contrast minimum everywhere and invisible on the
toolbar; it is now a two-tone ring. The three analysis switches had no
accessible name, and collapsed panel sections kept their controls focusable
while telling screen readers they were not there.

## For people packaging or auditing ALBIS

- Releases carry build provenance attestations and a CycloneDX SBOM, and
  `SHA256SUMS.txt` is now signed.
- CodeQL analyses the code on every pull request.
- `GOVERNANCE.md` and `SUPPORT.md` state the bus factor, the relationship to
  DECTRIS, and what response to expect. The Code of Conduct no longer routes
  harassment reports through a public issue.
- The Linux requirement was documented as `glibc 2.38+`; the builds have always
  required only 2.35, so Ubuntu 22.04 and Debian 12 are supported after all.
- Running from source works again: `python backend/app.py` had been broken for
  about seven releases. Use `python albis_launcher.py`.

Windows installers remain unsigned in 0.x — expect the SmartScreen prompt. From
1.0.0 the release will refuse to publish them unsigned.
