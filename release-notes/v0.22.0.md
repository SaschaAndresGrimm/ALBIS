The detector geometry gets a home of its own, and a manual override that lasts.

### Changed

- **Detector distance, pixel size, photon energy, beam centre and the geometry
  file moved to Data → Detector Geometry.** They describe the experiment, not
  the rings: they also drive the cursor's d readout, the peak table and series
  sums. ALBIS shows them from the image metadata, read-only, with a badge
  saying whether they came from the metadata, are incomplete, or are manual.
  Resolution Rings and Peak Finder show the values in effect in one line, with
  **Edit** to jump there.
- **Override manually, for metadata that is missing or wrong.** Switch it on
  and type the values the metadata gets wrong; the fields you change are
  outlined and show what the metadata says. Your values replace the metadata
  for every image, from file to file and across sessions, until you switch the
  override off or press **Reset to metadata**. Fields you leave alone keep
  following the metadata, so the energy still changes frame by frame.
  Dragging the beam centre on the image counts as a manual edit.
- **Pixel size has separate X and Y fields.** A non-square pixel size
  stretches the image as you type it.
- **One rule for every source.** A typed value used to be kept, locked or
  silently replaced by the next file's header, depending on where the data
  came from. Now it behaves the same everywhere, and a file that lacks a value
  shows it as missing instead of quietly reusing the previous file's.

---

Nothing changes in how ALBIS reads, displays or exports your data. If you
corrected geometry values by hand before, you will find them under
**Data → Detector Geometry** now.
