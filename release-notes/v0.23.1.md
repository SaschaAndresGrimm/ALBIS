Fixes for the live monitor, the spot finder, saved settings and window captures.

### Fixed

- **The SIMPLON monitor shows every new frame.** During an acquisition with
  few photons per frame, the first image appeared and later ones mostly did
  not, although opening a new window showed the latest. ALBIS took new sparse
  frames for the one already on screen. It now recognises each frame by the
  detector's image number and its full content.
- **Your settings survive a restart.** Open Recent, a manual detector geometry,
  the interface language, the panel layout and the file browser's last folder
  came back empty every time ALBIS was restarted. ALBIS now starts on the same
  address each time, where the browser keeps them. The first start after
  updating still begins fresh; from then on everything is kept.
- **The spot finder keeps sharp, strong reflections.** A very intense spot
  whose intensity sits mostly in one pixel was discarded as a detector glitch.
  On a diamond-anvil-cell series, about three in four of the spots it missed
  are now found, without adding noise and without slowing down.
- **Save As → Viewer Window matches the screen.** Zoomed in and scrolled, the
  image in the capture was shifted against its pixel values, or missing.

### Changed

- **ALBIS describes itself the same way everywhere**, from the README to the
  About dialog, as a viewer for DECTRIS detector data.
- **The Zenodo record links to the installers and the documentation.**

---

Update if you watch acquisitions with the SIMPLON monitor, use the spot finder,
or want ALBIS to remember your settings between sessions.
