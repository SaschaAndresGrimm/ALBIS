Four things the beta testers caught in a day. Nothing new, everything that
was already there working properly.

### Fixed

- **The folder chooser now says what it is choosing.** Every one of them was
  titled *"Select Auto Load folder"* — the log directory, the export folder,
  the data root, all announcing themselves as autoload. Each says its own
  thing now, in all thirteen languages.
- **On Windows, the chooser opens in front of the browser.** It was opening
  *behind* it: invisible, with ALBIS looking frozen. It had no owner window, and
  Windows makes no promise about the foreground in that case.
- **Settings shows the data and log folders it is actually using.** Both boxes
  were blank on a default install, because blank is not a missing value there —
  it means *work the location out at start*. The real path now shows as a
  placeholder, so it still counts as "follow the default" when you save.
- **Gap and defective pixel counts are real for CBF, TIFF and EDF.** They read
  the mask array and nothing else, and only HDF5 files have one — so the panel
  reported zero for every other format. A PILATUS frame marks its module gaps
  `-1` and bad pixels `-2` in the pixels themselves; the frame in our test data
  holds 16,558 gaps and 19 bad pixels, 5.5% of it, all of it counted as nothing.
