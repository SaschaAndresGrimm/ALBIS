**You Only Live Twice**: a patch release for Windows. After an upgrade from an older version, ALBIS opened the browser on a page that never loaded. It also makes rings and markers easier to see on light images.

### Fixed

- **ALBIS starts again on Windows after an upgrade from an older version.**
  Installing 0.48.0 or 0.49.0 over an ALBIS from before 0.48 could leave
  the browser on a page that never loaded. The installer copied the new
  files over the old ones and kept the rest. One old leftover made every
  request fail, and nothing about it reached the log. The installer now
  clears out the old files first. ALBIS no longer depends on what an
  earlier version left behind, and errors like this now show up in
  `albis.log`.

### Changed

- **Rings and markers stay readable on a light image.** On a colour map
  that is white where nothing was counted, such as the default Albula HDR,
  the halos behind peak circles and rings are now drawn dark and heavier.
  On a dark image nothing changes. The highest-pixel squares of the
  Min/Max Finder are coral instead of pink, so they no longer look like
  part of the magenta reference rings.

---

Windows users should update, in particular anyone whose ALBIS opens a page
that never loads. If you are stuck on such a page now, uninstall ALBIS and
install 0.49.1. The new installer will then keep upgrades clean. On macOS and
Linux, the update brings only the clearer rings and markers. The full list is
in the [changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
