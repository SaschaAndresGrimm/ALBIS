**One Shall Be the Number Thou Shalt Count**: the zoom now counts the pixels of your screen, so 1x shows each detector pixel on exactly one of them, and the downloads list everything inside them and carry current security libraries.

### Added

- **1:1 shows the data pixel for pixel.** The new **1:1** button next to
  **Fit to Window** puts each detector pixel on exactly one pixel of your
  screen: nothing enlarged, shrunk or blended. It is also in the command
  palette as **View: Zoom 1:1**.

### Changed

- **The zoom counts screen pixels.** 1x used to mean one pixel of the page,
  which a Retina screen draws with 2 × 2 of its own. On Windows at 150 %
  scaling, some detector pixels were drawn wider than their neighbours, which
  could put stripes into fine structure. Now 1x means one detector pixel on
  one screen pixel on any display. At a whole-number zoom every pixel is
  equally wide. **As on screen** exports at the screen's full resolution.
- **Zoom into a box on an ROI plot with right-drag**, the same as drawing a
  region on the image. Shift-drag sets the contrast on the image, so it now
  pans on a plot instead.
- **Each download lists what is inside it.** Windows, macOS and Linux each
  come with their own bill of materials (`ALBIS-<platform>-<version>.cdx.json`),
  so a security review can check exactly what a facility installed.
- **Current OpenSSL, SQLite and expat in every download**, on Python 3.13.18.
  The interpreter on macOS and Windows had carried older versions with
  published advisories. Each release is now checked against the public
  vulnerability databases before it is published. Libraries ALBIS never used
  (lxml, Pillow, SQLite and a few others) are no longer included.

### Fixed

- **An ROI plot can be dragged up and down from the start.** A freshly opened
  plot used to snap back, which looked like a reset.

---

Everyone can update; nothing changes in how files are read. On a Retina or
other high-resolution screen the zoom numbers are now twice what they were for
the same view: this is the new count, not a change in what you see. To box-zoom
on an ROI plot, use right-drag instead of Shift-drag. The full list is in the
[changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
