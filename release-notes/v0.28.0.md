**Common Ground:** one detector list for everyone on an ALBIS server, plainer names in the panel, and a tidier Detector tab.

### Changed

- **The known detectors belong to ALBIS, not the browser.** The list under
  the detector address fields is now kept on the computer ALBIS runs on. It is
  the same in every browser, survives upgrades, and on a shared ALBIS server
  everyone sees the same list. A setting, `known_detectors_file`, can point it
  at one file on a network drive to share a list across a lab. Lists kept in
  the browser by 0.27.0 are taken over the first time.
- **The Overlay tab is now the Analysis tab.** It holds the ROI statistics,
  resolution rings and the peak finder; the panel reads View · Data · Analysis
  · Detector.
- **Single image and Live.** In the beta Detector tab, "Snap" and "Continuous"
  are now **Single image** and **Live**, and "Live view" is now **Show images in
  ALBIS**. These settings and the exposure and rate fields sit behind a ⚙ at the
  end of the button row, folded away by default.

---

Update if you use the detector list on more than one browser or share an ALBIS
server, or if you look for ROI and rings: they are now in the **Analysis** tab.
In Docker, mount `/home/albis/.config/albis` to keep the detector list when
the container is replaced.
