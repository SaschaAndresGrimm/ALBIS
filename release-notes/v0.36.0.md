**Duty Free:** feedback from a week of imaging measurements, turned into features. Keep the detector counting all the time, export TIFFs in the data type your processing software expects, and convert long series about five times faster.

### Added

- **Full duty cycle in detector control.** A chain between **Frame time**
  and **Count time** keeps them linked, so the detector counts all the time
  but for its readout. Change either one and the other follows. Click the
  chain to set them independently again; a shorter count time set elsewhere
  shows as **Independent**.
- **Unsigned 16- or 32-bit TIFF exports.** **Convert Dataset** has a
  **Data type** choice for software that needs a fixed type. Gaps, bad and
  saturated pixels become the type's highest value (65535 for 16 bits), and
  counts that do not fit are clipped, never wrapped around. The dialog warns
  beforehand when the data can count higher, the export says how many pixels
  were clipped, and each file's header records it.
- **Convert Dataset says what it will write** before it starts: how many
  files, which type, about how large, and their names. Its explanations sit
  behind **(?)** buttons, so only what needs attention stays in sight.
- **Linux arm64 builds**, for 64-bit ARM machines such as the NVIDIA DGX
  Spark: an AppImage, an AppImage bundle and a tarball.
- **JUNGFRAU automatic pedestals** in the detector panel.
- **A more useful log.** Exports and Combine Frames say what they did, how
  long it took and where the files went; startup names the ALBIS version and
  system; a detector that stops answering is logged once, not every second.

### Changed

- **Convert Dataset is about five times faster** with flatfield and
  inpainting: 2000 projections of 1 Mpx in under 30 s instead of about
  2.5 min, with identical files. It stays within the machine's memory on
  large detectors, refuses an export the disk cannot hold, and keeps the
  viewer responsive while it runs.
- **Saturated pixels are white on ALBULA HDR**, as ALBULA draws them.
- **The log has one aligned layout**, each request once, without the
  interface's routine polling.
- **The default output folder is named after the series**, not the frame
  that happens to be open.

### Fixed

- **Convert Dataset opens afresh after an export**, with Start Export instead
  of the last export's Open Image.
- **A frame too large for the GPU says so**, instead of leaving the image
  black.
