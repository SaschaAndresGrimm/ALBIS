**3rd Rock from the Sun** (not the 3th): a small bugfix release that sweeps up after 0.39.0's big move.

### Fixed

- **The log file no longer gains a line every second while the handoff queue
  answers with an error.** Since 0.39.0, a failing handoff queue, which a data
  pipeline uses to have ALBIS open a file, wrote a warning to the log once a
  second. ALBIS stays quiet about it again, as it did up to 0.38.1; a server
  that cannot be reached at all is still logged.
- **Combine Frames writes "every 2nd frame", not "every 2th frame".** With a
  frame step, the description saved in the TIFF header got the ending wrong:
  2th, 3th, 21th. It now reads 2nd, 3rd, 21st.

---

Everyone on 0.39.0 can update; nothing moved. Behind the scenes, the largest
files that 0.39.0 left alone (the image readers, exports, Combine Frames, the
HDF5 reader, the file browser, ROI statistics, the pixel mask and the Detector
tab) were split up the same way. They were checked against 0.39.0 output by
output, window by window, and on a real PILATUS4. If anything behaves
differently from 0.39.0, that is a bug: please report it, with Help → View Log
if you can.
