**Infinite Improbability Drive**: the engine that gets the Heart of Gold anywhere without the tedium of crossing the space in between. 0.42.3 cuts the waiting out of opening a file, and shows that ALBIS is working during whatever wait remains.

### Fixed

- **The first file you open shows that it is loading.** The start screen now
  says "Loading file…" with a spinner from the moment you choose a file until
  its image appears. It used to sit unchanged for several seconds, as if
  nothing had happened. If the file fails to open, **Open file** comes back.
- **The first file opens sooner.** ALBIS now loads its HDF5 and CBF/TIFF
  readers in the background as it starts, while you are still choosing a
  file, instead of making the first file wait a second or two for them.
- **An image in a folder of thousands of files opens without a pause.**
  Opening a CBF, TIFF or EDF image in a folder of 20,000 frames took 0.75 s
  just to find the rest of its series, and the same again for every file
  auto-load picked up. It now takes 0.13 s on a local disk, and the gain is
  larger on the network storage beamlines keep their data on.
- **An HDF5 file's pixel mask is read once, not twice,** when the file opens.
  A file without a mask no longer writes a warning to the log, since that is
  normal.

---

Everyone can update; nothing about files, settings or the image changes.
Most noticeable for anyone who opens images from large folders or watches a
folder with auto-load, and for the first file after starting ALBIS.
