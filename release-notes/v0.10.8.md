# ALBIS 0.10.8: Just Type the IP

A usability release for live SIMPLON monitoring. Setting up a detector stream was easy to get wrong and hard to diagnose: the address field rejected the bare IP most people type, its example suggested a port SIMPLON does not use, and anything that went wrong reported the same three words. All three are fixed.

## Highlights

- **The detector address accepts what you actually type.** Enter `192.168.1.10` and the field fills in `http://` for you, showing the canonical address it will use. Pasting a URL copied out of the SIMPLON docs works too — the `/monitor/api/1.8.0/…` path is trimmed back to the host. Mistyped separators like `http//host` are repaired. An explicit port is always kept; leaving it out means the detector default of 80. Previously a bare IP was rejected outright, and the placeholder suggested port 5000, which SIMPLON does not listen on.
- **A Test button that tells you what is wrong.** Press **Test** (or Enter in the address field) to check the connection before starting. On success it names the detector and serial number, confirming the address points at the instrument you meant. On failure it names the cause: unknown host, connection refused on the port you gave, no SIMPLON API at the API version configured, or no response at all.
- **Live monitoring says why it stopped.** A failing poll now reports, for example, `SIMPLON: Connection refused on port 5000 — SIMPLON normally listens on port 80.` instead of `SIMPLON: error`. Every message is translated in all 13 languages.
- **Addresses saved by older versions start working.** A bare host stored in your settings is normalized when they load, instead of failing on every poll forever.

## Also in this release

- New `GET /api/simplon/probe` endpoint backing the connection test. A detector that does not answer is reported as a diagnosis (`200` with a classified `code`), not a transport error.
- `502` responses from the SIMPLON routes now carry a classified object detail so clients can localize the reason. See `docs/API_CONTRACTS.md`.
- Dependency updates: FastAPI 0.141.1, Uvicorn 0.52.1, cbor2 6.1.4.
