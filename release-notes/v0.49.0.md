**A View to a Kill**: a release for the ROI tools. The histogram now opens on a view of where the pixels are, instead of being killed by one bright outlier. A region can be typed in or set to the whole frame, and every plot and statistic can be taken away as a PNG or pasted into a spreadsheet.

### Added

- **Whole frame.** One click next to **Clear ROI** makes a box over the whole
  detector, so the profiles and the histogram cover every pixel.
- **Type a box or line ROI.** **Start X/Y** and **End X/Y** fields under the
  mode menu set the region exactly, for the same region on another file or one
  a colleague gave you in numbers. They follow the ROI while you drag it.
- **Copy the statistics.** **Copy**, next to **Export CSV**, puts the full
  values on the clipboard as a table that pastes into a spreadsheet as cells,
  with the file, frame and ROI on top.
- **Save a plot as a PNG.** A download button on each profile and on the
  histogram saves it as shown, titled and labelled with the file, frame and
  ROI.

### Changed

- **The ROI Histogram shows the bulk of the pixels.** One bright pixel no
  longer squeezes everything into the first bar. The plot opens on the range
  holding 99.8 % of the pixels and says in its corner how many lie beyond it
  ("234 px at or above 198 →"). Zoom out to see them. The count axis starts
  logarithmic. With whole-number data every bar holds the same number of
  values, so there are no more comb patterns. On a whole EIGER2 16M frame it
  takes about 4 ms instead of 0.8 s per frame step.
- **The histogram is switched on in its own title**, under the profiles, and
  opens right there.

### Fixed

- **Zooming out on a plot's count or intensity axis stops** once the data
  fills a quarter of the axis, or two decades past it on a log axis. Counts no
  longer zoom below zero. A few wheel turns used to take a log axis to 10⁵⁰.
- **Log axes read 1e+3, 1e+6, …** instead of 1.000000e+3.

---

Everyone who works with ROIs should update, in particular anyone using the
histogram on diffraction data. The histogram toggle moved from above the
profiles into the histogram's own title. Nothing changes in how files are read
or written. The full list is in the
[changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
