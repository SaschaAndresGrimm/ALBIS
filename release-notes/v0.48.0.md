**The World Is Not Enough**: when one frame is not enough, the viewer now shows several added together, so a weak signal stands out, and the downloads are much smaller.

### Added

- **Show several frames as one.** The new button next to the frame number,
  **1 frame** at first, adds up consecutive frames: type any count from 1 to
  1000, or pick 2, 5, 10, 20, 50 or 100. At frame 121 with 10, you see frames
  121 to 130 as one image, and the timeline reads **121–130 / 3600**. Weak
  reflections and diffuse scattering show up that a single frame hides.
  **Mean** instead of **Sum** keeps counts per frame. `[` and `]` take fewer
  or more frames.
- **Look through a long series quickly.** The step follows the count, so the
  arrow keys, ◀ ▶ and playback go ten frames at a time and show each frame
  exactly once. Set the step by hand, to 1 for example, for a sliding window.
- **Statistics see what you see.** ROI numbers, profiles, the peak finder and
  pixel values all use the combined image. Gaps and defective pixels stay
  masked rather than adding up to huge counts, for EIGER and PILATUS data
  alike. A sum loads about as fast as a single frame: ten frames of a 1M
  EIGER2 file take about 0.1 s. This works for HDF5 files and for series of one file per frame (CBF,
  TIFF, EDF), not for a live detector. The footer says **Sum of 10 frames**
  while it is on; click it to change the count.
- **Exports write what the view shows.** With frames combined, **Convert
  Dataset** writes the frames on screen as one file, or one file per window
  for a range, with names ending `_sum10` and a header that says
  `sum of 10 frames 121-130`. Inpaint, Flatfield and the 16- and 32-bit types
  apply as for a single frame. **Export Animation** renders each window as one
  frame.

### Changed

- **Much smaller downloads.** Linux is less than half its former size (arm64:
  52 MB instead of 119 MB, and 32 MB for the new tarball), and every platform
  is about 13 MB lighter. The
  Linux tarball is now a `.tar.xz`, which `tar -xf` unpacks as before, and the
  macOS disk image uses stronger compression.
- **Calmer export dialogs.** When **Include overlays** or **Pixel values** is
  not available in **Export Image** or **Export Animation**, the reason is in
  its tooltip instead of written underneath.

---

Everyone can update; nothing changes in how files are read or written unless
you turn the new **Sum** on. One exception: the downloads no longer carry
seven HDF5 compression filters made for simulation and climate data (ZFP, SZ,
SZ3, SPERR, HTJ2K, JPEG-LS, bzip2). Everything DECTRIS detectors and
Jungfraujoch write still opens. A file compressed with one of those filters
lists its datasets but cannot show a frame; ALBIS run from the source code
still reads it. Linux users: the download name now ends in `.tar.xz`. The
full list is in the
[changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
