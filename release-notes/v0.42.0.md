**Don't Panic**: the answer to life, the universe and everything turns out to be a version number. ALBIS 0.42 opens Diamond's NeXus collections and draws correct resolution rings for a detector on a 2θ arm. Thank you to Mark at **Diamond Light Source beamline I19** for the questions that started it.

### Added

- **NeXus files open.** ALBIS opens `.nxs` files as Diamond's Eiger beamlines
  write them, with every frame of the collection and its energy, distance,
  pixel size and beam centre. The file dialogs and the installers on Windows,
  macOS and Linux offer `.nxs` too.
- **A data file opened on its own finds the rest of its collection.** Opening a
  `_000001.h5` now takes the geometry and the pixel mask from its collection's
  `.nxs`, `_master.h5` or `_meta.h5` in the same folder. The resolution rings
  work, and the detector gaps are masked, without typing anything in. In the
  file browser's series view, a collection shows as one entry, its `.nxs`.
- **Resolution rings for a detector on a 2θ arm.** When a NeXus file describes
  how its detector is mounted, ALBIS places the detector the same way and
  agrees with DIALS to within a billionth. At I19-2 the arm sits at 20°, and
  the real beam is 413 pixels from the beam centre the file states. The rings,
  the cursor's **d** and the beam-centre cross now follow the tilted detector.
- **Detector 2θ by hand.** For files that don't describe their arm (CBF, TIFF,
  older DECTRIS masters), **Data → Detector Geometry** has a **Detector 2θ (°)**
  field and the direction the arm swings. Older DECTRIS masters fill in the
  angle themselves; you choose the direction.
- **Rings can be dragged on tilted and multi-panel detectors**, as on a flat
  one.
- **ALBIS says when it couldn't read its config file**, with a warning at
  startup and the reason in **Settings**. A stray comma no longer just looks
  like ALBIS ignoring you.

### Changed

- **Zooming and panning no longer make the image jump.** The wheel zooms about
  the cursor, and the slider about the middle of the view. A zoomed-out image
  can be moved around the window, and the overview outlines exactly what is in
  view.
- **File → Open starts in your data folder**, then in the last folder you
  picked from.

### Fixed

- **Frames from a NeXus file load twice as fast**: 18 MB instead of 36 MB per
  Eiger2 4M frame. The detector's gaps are no longer shown as four billion
  counts.
- **On Linux, ALBIS is offered for `.h5` and `.hdf5` files.** The installer
  registered a media type no Linux distribution uses.

---

Everyone can update, and anyone at Diamond, I19-2 especially, should. On Linux,
run the AppImage installer again so the file manager offers ALBIS for HDF5 and
NeXus files. The new 2θ field is in **Data → Detector Geometry**, under **Beam
center**. So long, and thanks for all the frames.
