The beta Detector tab now works with an EIGER1 and other SIMPLON 1.6 detectors.

### Fixed

- **Older detectors connect.** The Detector tab always spoke SIMPLON 1.8, which
  a SIMPLON 1.6 detector such as an EIGER1 refuses. ALBIS now asks the detector
  which version it speaks and uses that.
- **Their readings are right.** On 1.6, temperature, humidity and high voltage
  are shown (high voltage in volts), and the free storage on the detector is no
  longer shown a thousand times too small.
- **Every setting arrives.** An EIGER1 answers one request at a time; ALBIS now
  asks it that way, so the detector's name and all its settings show on every
  connect. On any detector, a request that times out is asked again once.

### Added

- **Quick access to the detector's web interface.** Once connected, the address
  under the detector's name opens the detector control unit's own web page in a
  new tab.

### Changed

- **The Detector tab is described as what it is:** a quick way to test a
  detector, not a control system. The README, the User Guide ("Test a detector")
  and the help page say what it is for and what not, and so does the tab itself
  until it is connected.

---

Update if you use the beta Detector tab with an EIGER1 or another SIMPLON 1.6
detector. The tab stays hidden until you switch it on under Settings → Viewer.
