**With a Little Help from My Friends**: a User Guide that walks a newcomer through ALBIS with pictures, an interface that looks and behaves the same in every browser, and a handful of fixes.

### Added

- **The User Guide starts with a walk-through and has pictures.**
  **Getting started** takes you from opening a file to saving a picture in
  eight steps, on ten images of an insulin crystal you can download from the
  ALBIS repository. Every section shows the controls it describes, task
  sections open with their steps in short, and a glossary explains the terms,
  from BG and FG to threshold.
- **Help points newcomers to the walk-through.** Help (F1) links to Getting
  started from its "New here?" box and its Quick start.

### Changed

- **One Auto toggle for contrast.** The Auto Contrast button and the Auto
  checkbox, which switched the same thing, are one **Auto** button under the
  histogram, lit while the contrast follows every frame.
- **The menu bar, toolbar and status bar stay legible over the image.** They
  are frosted and nearly opaque, and fade to 70% when idle instead of about
  40%. The menus are frosted too, no longer see-through.
- **Controls look the same in every browser.** Checkboxes, dropdowns,
  sliders, number spinners and section chevrons are drawn by ALBIS in its
  dark style, where Chrome, Firefox and Safari each drew their own. Every
  control shows the same blue focus ring when reached with the keyboard.
- **Dialogs are tidier.** Export dialogs show what is being exported as plain
  text instead of boxes that looked like fields, and Settings keeps one size
  with its fields lined up.
- **The zoom slider is logarithmic.** Each doubling of the zoom takes the
  same length of track, so the zooms most images are viewed at have room;
  arrow keys zoom by about a fifth, Page Up and Page Down double or halve.
- **Edge handles on a box ROI** move one side at a time, and the ROI plots
  open at a readable 220px.

### Fixed

- **The cursor readout moves clear of the magnifier as it appears,** instead
  of staying half under the lens until the mouse moved.
- **Export Animation names the Peak Finder by its name,** not "the spot
  finder", in every language.
- **The arrow keys stay on the panel tabs that are shown,** instead of moving
  to the hidden Detector tab and losing focus.
- **The file browser's columns line up** under their headings, dialogs open
  above the folded panel's Open menu button, and the File menu no longer
  looks pressed when closed.
- **Running from a clone inside a container, the update notice says
  `git pull`** instead of offering a Docker image that was never run there.

---

Update for the new look and the steadier controls; nothing has moved, and
the Auto button sits where the Auto Contrast button was. New to ALBIS, or
showing it to someone who is? Start with **Getting started** in the User
Guide, linked from Help (F1).

For contributors: the repository is ready to work on together with a coding
agent. `AGENTS.md` and per-area notes say where things go, step-by-step
recipes cover visible strings, HTTP endpoints, checking the interface by eye
and releasing, decision records explain the deliberate choices, and a
devcontainer gives a ready sandbox. The User Guide's pictures are made by a
script, `npm run guide:screenshots`, so they stay current with the interface.
