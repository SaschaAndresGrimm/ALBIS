**Quantum of Solace**: a patch release for anyone who zooms into floating-point images, where the pixel values now stay put. It also brings a tidier Data Source section. Thanks to Rissi for finding the float bug.

### Fixed

- **Pixel values on floating-point images no longer come and go as you
  zoom.** At many zoom levels one value was too wide for its pixel, and then
  none were drawn at all. Which zoom levels were hit depended on the values in
  view, so the numbers seemed to appear at random or not at all. Every value
  now fits its pixel. Should one still not fit, only that one is left out.
  The same applies to **Export Image** and **Export Animation** with pixel
  values. Thanks to Rissi for the report.
- **The focus ring is no longer cut off** on the first and last field of a
  side-panel section, the **Data Source** field for one.

### Changed

- **The Data Source section lines up.** Labels, fields and buttons sit in the
  same columns. **Watch folder** sits right under **Folder** and shows its
  options when switched on. **File System** (on a remote server) comes before
  **Folder**, whose list it decides. **Advanced source settings** is now
  **Connection options**. It is shown only for a live source and holds only
  what can stay at its default. **Test** sits under the address it tests.
- **A live source without its address asks for it.** SIMPLON Monitor or
  JUNGFRAUJOCH Preview with an empty address now says "Enter the detector's
  address to begin." and puts the cursor in that field. Before, the section
  claimed the source was active.
- **The Peak Finder no longer repeats the detector geometry** that Resolution
  Rings already shows. Hold the mouse over the **d (Å)** header to see where
  those values come from. The status line counts peaks "on this image",
  which stays right when several frames are added together.

---

Everyone can update, in particular anyone looking at floating-point data:
corrected, normalised or summed images, or files written as float. Nothing
changes in how files are read or written. The full list is in the
[changelog](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/CHANGELOG.md).
