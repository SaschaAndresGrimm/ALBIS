**Battery Boys, Flat Out:** flatfield correction, for Carlo Amato and the imaging team.

### Added

- **Flatfield correction.** A new **Flatfield** section in the **Analysis** tab
  divides every image by a flat — an image of the beam taken with no sample —
  so the beam's profile cancels out and only the sample remains.
  - **Use current image** keeps the image on screen as the flat, for instance a
    single image taken just before a scan. It is saved as a TIFF in the data
    folder's `flatfields/`, so it can be used again. **Choose file…** takes a
    TIFF or CBF instead.
  - **Scale:** **Counts** keeps the image's own scale; **Transmission** gives 0
    to 1, where 1 means nothing was absorbed.
  - Pixels the flat cannot divide by are filled by **Inpainting** when it is on,
    after the correction.
  - The image, the contrast, the ROI statistics, PNG and GIF exports and live
    images all follow; the footer shows **Flatfielded**.
  - **File → Convert Dataset** has a **Flatfield** box: TIFF files hold the
    corrected values as 32-bit floats, and the header names the flat.

---

Update if you work with imaging data. For a less noisy flat, average a series
first with **Combine a series into one image** and choose the result. See
"Flatfield correction" in the User Guide.
