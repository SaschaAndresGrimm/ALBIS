Sharp figures out of ALBIS: a dedicated image export, pixel values in exports, and exports that look like the screen.

### Added

- **File → Export Image… (⇧⌘E) writes a PNG for slides and papers.** It
  enlarges by 1×, 2×, 4× or 8× without smoothing, so every detector pixel stays
  a sharp square instead of being blurred by whichever program shows it. The
  default is the smallest size at least 2000 pixels wide. A print resolution
  (300 dpi by default) is stored in the file, and the dialog shows the printed
  size. **Include overlays** draws the resolution rings, found peaks and the ROI.
- **As on screen.** Export Image and Export Animation can both export at the
  viewer's zoom, so a zoomed-in visible area comes out exactly as it looks.
- **Pixel values in exports.** A **Pixel values** checkbox draws each pixel's
  value into the PNG, or into every GIF frame from that frame's own data. It is
  available whenever the exported pixels are large enough to hold the values,
  which in practice means As on screen while zoomed in.
- **Export Animation enlarges** to 2× and 4×, sharp, as Export Image does.

### Changed

- **Save As → Visible Area saves what you see.** It saves at the viewer's zoom,
  each detector pixel a sharp block, instead of a stamp-sized image at one pixel
  per detector pixel. Full Image still saves the exact data.
- **Export Animation's size** is chosen like Export Image's: every option shows
  its pixel size, and the default is the largest size up to 1600 pixels on its
  longer side, instead of a fixed 50% that turned a Pollux frame into a thin
  strip.
- **The export dialogs say why an option is unavailable,** right under it,
  instead of only on hover.
- **No more hover hints that just repeat a button's label.**

### Fixed

- **Save As → Viewer Window was blurry when zoomed in.** The image in the
  capture is now as sharp as on screen.
- **Export Animation drew non-square pixels square,** squashing the image. GIFs
  now keep the true pixel proportions, as the viewer and the PNG export do.

---

Update if you put ALBIS images on slides, in papers or in reports: Export Image
is new, and the Save As captures are now sharp. Export Image sits at the top of
the File menu, next to Export Animation.
