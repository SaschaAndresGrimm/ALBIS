**Go Go Gadget Inspector**: the File Inspector, the panel that shows what an HDF5 file holds besides its images, grows a gadget for every job, from values in the tree to a chart of every frame.

### Added

- **Statistics and a chart for arrays of numbers.** A numeric dataset shows
  its minimum, maximum and mean over the whole dataset, and how many values
  are NaN or infinite. A one-dimensional array, such as the start time of
  every frame, is drawn as a line chart: a jump, a reset or a single spike
  shows at a glance. Point at it to read the values.
- **Show in viewer.** A dataset the **Dataset** list offers, such as a flat
  field found while browsing, opens in the viewer with one click.
- **Copy a path or a value.** The path above the details is a breadcrumb with
  a copy button, and a single value has **Copy value**.

### Changed

- **Values right in the tree.** Fields that hold one value show it, with its
  unit (`NXmx`, `0.001 s`), where the tree said `object`. Text is called
  `string`.
- **Compact details.** Type, shape, data type and unit are one line
  (`dataset · 40000 · float64 · s`), the value comes next, and attributes
  follow without repeating what the line already says. Long values, such as a
  configuration stored as text, scroll in their own box, with JSON indented.
- **Links lead somewhere.** A link shows what it points to, read from the
  linked file; a link to a group opens like a group.
- **Search takes you there.** Results take the tree's place, name first with
  the match highlighted, and picking one selects it in the tree.
- **Keyboard and screen readers.** Arrow keys move through the tree and the
  search results, Enter opens, Esc clears the search, and screen readers hear
  a proper tree.
- **Calmer to use.** Clicking an open group selects it instead of closing it,
  each entry is marked as group, dataset or link, the tree can be dragged
  taller, and the status line names the file instead of announcing every
  click.
- **The User Guide** explains the File Inspector in a section of its own,
  with a picture.

### Fixed

- **One unreadable entry no longer empties the whole tree.**
- **Datasets and links line up with the groups beside them,** instead of
  sitting a column to the left.

---

Everyone can update; nothing moved except inside the File Inspector, which is
at the bottom of the **Data** tab when an HDF5 file is open. For anyone
reading the HTTP API: `/api/hdf5/tree` and `/api/hdf5/search` rows gain
`value` and `units`, `/api/hdf5/value` gains `stats` and `outline`, and
`dtype` reads `string` for HDF5 text where it read `object`
([API contracts](https://github.com/SaschaAndresGrimm/ALBIS/blob/main/docs/API_CONTRACTS.md)).
