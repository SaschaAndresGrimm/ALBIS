# ALBIS 0.15.0: Nothing Fails Quietly

Several buttons did nothing when they could not work, and said nothing about it.
Now every one of them explains itself.

## Highlights

- **Controls that cannot run are greyed out, with the reason on hover** — Export Animation, both Export CSV buttons, Convert Dataset, Save As, Close File. Reach one by keyboard shortcut instead and it says the same thing out loud. The peak list's Export CSV was the worst case: with no peaks found it returned in silence.
- **Disabled buttons now look disabled.** `.btn` had no disabled styling at all, so every inert button in every dialog looked perfectly clickable.
- **Series operations say why they will not start**, instead of leaving Start looking broken on a bad frame range. Twelve other failures now match their severity.
- **Screen readers get the toolbar.** The frame slider and frame number box have names, and the hint tooltips are announced rather than only drawn.
- **Export Animation is in the command palette**, and its shortcut shows as Ctrl+G off macOS.
