# ALBIS 0.9.10

ALBIS `0.9.10` is a small release with a very practical mission: keep detector data from quietly multiplying just because somebody dragged a file over the viewer with enthusiasm.

## Highlights

- Local ALBIS sessions now disable drag-and-drop uploads. Use **File -> Open...** to open files directly from their existing path without making a copy.
- Remote browser sessions still support drag-and-drop, but the UI now says the important word out loud: **Upload files**.
- Dragging files over the viewer now shows a clear overlay for both cases: upload when remote, no-copy guidance when local.
- Pointer-anchored zoom got a little more obedient around the pixel you are actually inspecting.
- Saturated pixels now use a cyan overlay so they stand out more clearly from other visual layers.
- macOS file picking now handles `.cbf.gz` files correctly.

## Why this release exists

Because data duplication should be a conscious workflow choice, not a side quest unlocked by dropping a file in the wrong place.

## Release nicknames

- Drop Responsibly
- Look, Don't Duplicate
- Upload When You Mean It
