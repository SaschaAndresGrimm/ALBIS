**Fill It In:** inpainting can now set the gaps to one value instead of interpolating across them.

### Added

- **A fixed value for inpainting.** The Inpainting section has a **Method**
  choice: **Interpolate**, as before, or **Fixed value**, which sets every
  flagged pixel to one value — the background, say, so the gaps disappear into
  it. **Background** and **Foreground** take the value from the current
  contrast's low or high end, as a whole count for integer data. The value then
  stays as it is when the contrast changes, so the same settings always export
  the same file. Saturated pixels and the margin work with both methods, and
  inpainted TIFF and CBF files say which value was used.

### Changed

- **Updated components:** FastAPI 0.143.0 and NumPy 2.5.4.

---

Update if you use inpainting and want the gaps to blend into the background
rather than be interpolated.
