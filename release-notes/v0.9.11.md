# ALBIS 0.9.11

ALBIS `0.9.11` is the "macOS finally gets the clipboard and a polite nod at the door" release: same viewer, same detector focus, much less Gatekeeper drama.

## Highlights

- macOS release builds are now signed with a Developer ID Application certificate.
- macOS DMGs are submitted to Apple notarization and stapled after acceptance.
- The portable macOS ZIP is rebuilt after stapling, so the `.app` inside carries the notarization ticket too.
- CI now verifies Developer ID signing, hardened runtime, Gatekeeper assessment, and stapled tickets before publishing macOS artifacts.
- Public release builds now fail early if macOS signing or notarization secrets are missing, instead of quietly producing suspicious-looking downloads.

## Why this release exists

Because detector software should be judged by its pixels, not by macOS asking whether it came from a mysterious alley.
