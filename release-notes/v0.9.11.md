# ALBIS 0.9.11: Gatekeeper Gets a Proper Handshake

This is the "macOS stops side-eyeing ALBIS" release.

The app is the same focused detector-data viewer, but the macOS packages now arrive with the paperwork Apple expects: Developer ID signing, notarization, stapled tickets, and CI checks that refuse to ship suspicious-looking macOS builds.

## What Changed

- macOS app bundles are now signed with `Developer ID Application: Sascha Grimm (26V56HK2Q2)`.
- macOS DMGs are submitted to Apple's notary service and stapled after acceptance.
- The macOS ZIP artifacts are rebuilt after stapling, so the `.app` inside carries the notarization ticket too.
- Release CI verifies Developer ID signing, hardened runtime, Gatekeeper acceptance, and stapled tickets before publishing.
- Missing macOS signing secrets now stop public releases early instead of quietly producing downloads that macOS treats like mystery luggage.
