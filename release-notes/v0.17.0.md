**Windows installers are signed.** SmartScreen now sees `DECTRIS USA Inc.`
instead of shrugging at an unknown publisher. That's the headline; the rest is
garnish.

### New

- **GIFs can carry your overlays.** Tick *Include overlays* for resolution
  rings and spot-finder markers. The finder re-runs on every exported frame, so
  markers sit on the spots in *that* frame — not wherever frame 1's happened to
  be.
- **One typeface.** ALBIS was quietly rendering in two: labels in one face,
  every dropdown and button in whatever the browser fancied. It now ships Inter
  and looks the same on a Mac, a workstation and the beamline box.
- **The image sits where there's room for it.** It used to centre itself under
  the side panel while leaving a wide empty stripe on the other side.
- **The cursor readout stopped fidgeting** — fixed-width digits, so X / Y /
  Value no longer shuffles as you sweep across the detector.

### Fixed

- The GIF progress bar no longer snaps back to 0% on success. Strange way to
  celebrate.
- Summed HDF5 outputs declare their frame-index base. Off-by-one belongs in
  nobody's figure caption.
- A cancelled series operation no longer leaves a half-written file wearing the
  finished name.
- The metadata panel no longer spins forever on a file it can't read.
- Large uploads no longer freeze the window.
- Controls no longer show two tooltips at once — one more than strictly needed.

### Quietly important

Ten real PILATUS frames and an EIGER2 TIFF had been sitting in this repository
unread. They now have tests: the CBF is decoded a second time by a reference
implementation written from the specification, and its metadata checked against
the numbers in the file's own header. A dependency bump can no longer change a
pixel value without saying so.
