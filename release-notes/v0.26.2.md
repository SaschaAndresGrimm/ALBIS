**Roll Call:** converted images now answer to their numbers, in order, and live images can be converted too.

### Added

- **Convert Dataset works for live sources.** With the SIMPLON monitor, a
  JUNGFRAUJOCH preview or the Remote Stream as the source, File → Convert
  Dataset saves the current image or every image in the live history as TIFF or
  CBF, with the energy, distance and beam centre the source reported. Before, it
  failed with "File not found".

### Changed

- **Wording for any lab or facility.** The Detector tab and the documentation no
  longer assume a beamline: "your instrument's control software", "a lab or
  instrument network".

### Fixed

- **Converted images read back as a series.** Files are named like a detector's
  own images, the number last: `series_190_00007.cbf`, or
  `series_190_thr2_00007.cbf` with several thresholds, one series per
  threshold. ALBIS, XDS, DIALS and ALBULA now read an export as a series of
  frames; before, the last number in the name was the threshold or a counter.
  Exporting again with overwrite off gives the whole export a new name
  (`series_190_2_…`) instead of renumbering some of its files.

---

Update if you convert datasets, or want to save images from a live source. Files
converted with an earlier version keep their names; convert again to get the
new ones.
