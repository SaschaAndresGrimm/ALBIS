# ALBIS 0.10.5: Now Where Was I?

The file browser grew up this release. It got a memory, learned to collapse a whole HDF5 series down to the one file you actually open, and finally stopped waving files in your face when all you asked for was a folder. Same dialog, a lot less friction.

## Highlights

- **It remembers where you left off.** The browser now reopens in the last directory you were in, instead of politely marching you back to the root every single time. Buried a dozen folders deep in `processed/`? It picks up right where you were. If that folder has since vanished, it quietly falls back to root — no dead ends, no stack traces.
- **A whole series, collapsed to its master.** The **First image only** filter now speaks fluent DECTRIS HDF5. A `PREFIX_master.h5` and its swarm of `PREFIX_data_000001.h5…` chunks fold down into the single file you actually open — the master — carrying a little badge that counts the data files hiding behind it. Standalone and summed `.h5` files are left exactly where they are.
- **A folder picker that picks folders.** When ALBIS asks you to choose a *folder*, the dialog now shows... folders. The file list, the format filter, and the series filter all step aside, the folders pane goes full-width, and the current folder comes pre-selected so **Select** is armed the moment it opens. No more clicking a file and squinting at a greyed-out button wondering what you did wrong.

## Under The Hood

- Last-directory memory rides the same `localStorage` prefs the browser already keeps for sort/format/view, and a stale path is caught by the existing server-side 404-to-root fallback — so it self-heals for free.
- HDF5 series detection is a strict `_master.h5` / `_data_NNNNNN.h5` matcher, so ordinary numbered `.h5` files never get grouped by accident. Backend and frontend aggregate identically, master always wins, and a lone data-only set falls back to its first file.
- Folder-only mode is one CSS class plus a couple of guards; file-open mode is byte-for-byte unchanged.
- Housekeeping: bumped `hdf5plugin`, a couple of Python deps, and ESLint via Dependabot.
